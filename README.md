## How to use this list

1. Open the official GitHub repository linked above.
2. Read the project’s own README and license.
3. Follow the GetBuddyAI guide for a condensed, checked setup summary (commands verified against upstream docs as of the guide’s update date).
4. Run everything locally or in an environment you control. Do not expose local services to the public internet unless you know what you’re doing.

## Notes

- Licenses vary. Some tools have commercial restrictions or non-commercial model weights.
- Model weights and third-party APIs have their own terms.
- GetBuddyAI publishes guides only. It does not host, sell, or provide support for these projects.
- Star or contribute to the upstream projects if you find them useful.
